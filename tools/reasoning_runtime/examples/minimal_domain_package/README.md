# Minimal Domain Package Example

This example shows the smallest useful domain package for `reasoning_runtime`.
It is intentionally not related to Tech Connector or DCC software.

Run from the repository root:

```powershell
python reasoning_runtime/examples/minimal_domain_package/minimal_domain.py
```

The example demonstrates:

- context ingress
- reasoning guidance
- structured tool metadata
- validation
- evidence policy
- escalation policy
- code-generation policy
- installing a domain package into `ReasoningKernel`
