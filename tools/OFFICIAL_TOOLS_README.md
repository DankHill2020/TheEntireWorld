# The Entire World Official Tools Bundle

This repository includes the complete optional first-party tools collection for
Tech Connector. It is one product bundle; the individual Maya, Blender,
Houdini, 3ds Max, MotionBuilder, Substance Painter, Unreal, utility, plugin,
and Qt directories are not separately licensed tool packs.

The bundle can be installed beside Tech Connector Core, kept in an independent
directory, or included in a combined installation. Add the bundle directory to
Tech Connector's configured project/tool directories. The
`official_tools_bundle.json` manifest lets Core recognize the collection and
its compatible versions without uploading the directory path or its contents.

Users may continue to connect their own project directories and independent
tools without purchasing this bundle. The source is publicly visible under the
source-available license, but official execution, packaged updates, and support
for this first-party bundle are controlled by the `official_tools_bundle`
capability in the user's signed entitlement.

The accompanying `tech_connector/LICENSE.md` controls use. Downloading or
possessing these files does not create an activated entitlement.
