# IDE Editor

v5.9 adds the first real IDE-style editor pass.

## Added

- Line numbers
- Current-line highlight
- Python syntax highlighting
- No-wrap code editing
- Tab inserts 4 spaces
- Auto-indent on Enter
- Auto-indent after `:`
- Find in file
- Go to line
- Duplicate line
- Comment/uncomment selection
- Trim trailing whitespace
- Cursor status: line/column
- Modified indicator
- Save still creates `.tew_backup`

- Problems panel
